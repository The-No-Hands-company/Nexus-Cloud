# Vision

Nexus Cloud is the cloud substrate and central hub for The No Hands Company.

## Goal

Build a self-hosted, federated cloud that can be run by one person, a team, or a community without depending on a hyperscaler, while giving the full Nexus Systems ecosystem one coherent control layer and system map.

## Organisation hierarchy

1. The No Hands Company
2. Nexus Systems ecosystem
3. Current ecosystem applications and protocol projects coordinated through Nexus Cloud

## First principles

- Sovereign by default
- Federated when needed
- Portable workloads
- Simple operator control
- No vendor lock-in

## Initial building blocks

1. Identity and trust
2. Node registration
3. Scheduling
4. Storage
5. Networking
6. Observability
7. Ecosystem topology and integration depth
